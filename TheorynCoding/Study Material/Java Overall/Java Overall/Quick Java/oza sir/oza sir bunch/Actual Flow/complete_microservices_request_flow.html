========================================================================================================================
                              L7 vs L4
========================================================================================================================


L7 - APPLICATION LAYER
|
+-- HTTP / HTTPS
|
+-- URL
|
+-- HTTP Method
|
+-- Headers
|
+-- Application-aware
|
+-- External Load Balancer
|
+-- API Gateway
|
+-- Example:
|      POST /exit
|      Authorization: Bearer <JWT>
|


L4 - TRANSPORT / CONNECTION LEVEL
|
+-- TCP / UDP
|
+-- IP + PORT
|
+-- Connection-aware
|
+-- Does NOT need to understand HTTP URL
|
+-- Internal Kubernetes networking
|
+-- Kubernetes Service
|
+-- Internal load balancing
|
+-- Example:
       10.10.2.15:8080

MEMORY:

PUBLIC:
Internet -> External L7 Load Balancer -> API Gateway

PRIVATE:
API Gateway -> Kubernetes Service -> Microservice Pods -> Database
Architecture memory:
PUBLIC: Internet → External L7 Load Balancer → API Gateway (Public/DMZ)
PRIVATE: API Gateway → Eureka → Kubernetes Service → Microservice Pods → Database

Load balancing: External L7 Load Balancer chooses the API Gateway Pod. Internal Kubernetes Service/load-balancing chooses an eligible microservice Pod. HPA decides the number of Pod replicas.
